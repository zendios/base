# Base for Unity games

- `com.zen.core`: Base.
- `com.zen.plugins.adzative`: Base Native Ad.

## Install

Download [Base-Installer.unitypackage](https://github.com/zendios/base/releases/latest/download/Base-Installer.unitypackage)
([all versions](https://github.com/zendios/base/releases)) and drag it into the Unity project. Then open
**Base > Hub > Setup**.
